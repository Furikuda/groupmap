# GroupMap

Find your peeps on a map.

## Install

```
apt-get install ruby ruby-bundler libsqlite3-dev
git clone https://github.com/Furikuda/groupmap/
cd groupmap
bundle config set --local path 'vendor/bundle'
bundle install
bundle exec rackup -p 4567        # or: bundle exec ruby index.rb
```

### Tests

```
bundle exec rake        # Minitest suite in test/
```

### Upgrading from the old database (once)

The database is now `db/fluff_v2.sqlite`. Convert the old one, check the output, then delete the script:
```
bundle exec ruby tools/convert_db_to_v2.rb      # reads db/fluff.sqlite, writes db/fluff_v2.sqlite
```

### Settings (environment variables)

| Variable | Default | |
| --- | --- | --- |
| `GROUPMAP_DB` | `db/fluff_v2.sqlite` | database file |
| `GROUPMAP_ADD_INTERVAL` | `3` | min seconds between two markers from one IP |
| `GROUPMAP_ADD_PER_HOUR` | `100` | max markers per IP per hour |
| `GROUPMAP_SQL_LOG` | unset | set to log every SQL query |

## Add a map

Install vips (`apt-get install libvips-tools`), then:
```
ruby tools/prepare_pic.rb pic.jpg public/group_pics/myconvention
```
This builds the tile pyramid and writes `manifest.json`; fill in the blanks:
```
{
    "name": "My Con 88",
    "shortname": "MC 88",
    "year": "2088",
    "url": "https://my.con/88",
    "source_pic": "pic.jpg",
    "source_photographer": "https://twitter.com/MyConBestPalPhotographer",
    "max_zoom": 7,
    "width": 20000,
    "height": 6000
}
```
`max_zoom`, `width` and `height` are filled in by the script (deepest tile level and pixel size of the tiled
picture). New folders and manifest edits are picked up without restarting the server.

To move all markers of a map after re-tiling it, see `tools/transform.rb`.
